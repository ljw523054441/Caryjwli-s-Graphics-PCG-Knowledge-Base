通过蒙特卡洛积分，将方向性的距离信息编码为球谐系数

## 1. 理论基础

### 1.1 数学定义

球谐投影的数学定义是：
$$c_{lm}​=∫_{Ω}​f(θ,ϕ)Y_{lm}​(θ,ϕ)dω$$
其中：
- $c_{lm}$是球谐系数
- $f(\theta, φ)$是要投影的函数（这里是距离值）
- $Y_{lm}$是球谐基函数
- $dω$是立体角微元

### 1.2 球谐基函数的基本形式
#### 1.2.1 复数形式（数学定义）
$$Y_{lm}(\theta, \phi) = N_{lm} P_l^{\,|m|}(\cos\theta) e^{im\phi}$$

其中：
- $N_{lm}$是归一化系数
- $P_{l}^{m}$是伴随勒让德多项式
- $i$是虚数单位
#### 1.2.2 实数形式（图形学使用）

实数形式由复数形式线性组合得到，消除虚数：

| 情况    | 公式                                                                                 |
| ----- | ---------------------------------------------------------------------------------- |
| m = 0 | $Y_{l0} = N_{l0} P_{l}^{0}(\cos\theta)$                                            |
| m > 0 | $Y_{lm} = √2 N_{lm} P_{l}^{m}(\cos\theta) \cos(m\phi)$                             |
| m < 0 | $Y_{lm}(\theta,\phi)=\sqrt{2} N_{l\|m\|}P_{l}^{\|m\|}(\cos\theta)\sin (\|m\|\phi)$ |

## 2. 球谐投影积分的离散化实现

### 2.1 蒙特卡洛积分近似

代码用**离散求和**逼近**连续积分**：
```C
// 核心投影代码
float sh_basis = SH(l, m, theta, phi);
float contribution = val * sh_basis * solid_angle;
```

这对应公式：
$$
c_{lm} \approx \sum_{i=1}^{N} f(\theta_i, \phi_i) Y_{lm}(\theta_i, \phi_i) \Delta\omega
$$
其中 $Δω = 2π/N$ 是每个样本代表的立体角。

### 2.2 实现步骤详解

#### 2.2.1 生成采样方向
```c
// 生成均匀的半球采样方向 
vector2 u = rand(seed + set(i * 0.34, i * 0.78)); 
vector local_dir = sample_hemisphere_uniform(u); 
vector dir = local_dir * basis_mat;  // 变换到世界空间`
```

这里的关键是**均匀半球采样**函数，确保采样点在半球上均匀分布，满足蒙特卡洛积分的要求。
```c
vector sample_hemisphere_uniform(vector2 u) {                                 
    float phi = u.x * 2.0 * PI;
    float z = u.y; // 在高度上均匀分布
    float r = sqrt(1.0 - z * z);
    return set(r * cos(phi), r * sin(phi), z);
}
```

#### 2.2.2 计算方向上的函数值
```c
float val = 0.0; 
if (prim != -1) {
     val = distance(@P, hit_pos);  // 击中：返回实际距离 
} else {     
	 val = max_dist;              // 未击中：返回最大距离 
}
```

这个距离值就是我们要投影的函数 $f(\theta, φ)$，表示在该方向上直到遇到几何体的"开阔程度"。

#### 2.2.3 计算球谐基函数值
```c
// 将方向转换为球坐标 
float theta = acos(dir.z);  // 与Z轴的夹角 [0, π] 
float phi = atan2(dir.y, dir.x);  // 方位角 [0, 2π]  

// 计算该方向的球谐基函数值 
float sh_basis = SH(l, m, theta, phi);
```

##### 2.2.3.1 `SH()`函数
计算对应 $(l,m)$阶的**实数形式球谐函数**在方向 $(θ, φ)$上的值。
```c
float SH(int l; int m; float theta; float phi) {
    float sqrt2 = 1.41421356;
    if(m == 0) return K(l, 0) * P(l, m, cos(theta));
    else if(m > 0) return sqrt2 * K(l, m) * cos(m * phi) * P(l, m, cos(theta));
    else return sqrt2 * K(l, -m) * sin(-m * phi) * P(l, -m, cos(theta));
}
```
这就是上述1.2.2节实数形式的直接实现：
- **m=0**：只有径向部分，无方位角依赖
- **m>0**：使用 $cos(mφ)$项
- **m<0**：使用 $sin(|m|φ)$项，注意负号处理

##### 2.2.3.2 K() 函数 - 归一化系数（上述实数形式中$N_{lm}$项）

**数学公式**
$$K_{lm}=\sqrt{\frac{(2l+1)(l-|m|)!}{4\pi(l+|m|)!}}$$
这是**实数球谐的归一化系数**，确保：
$$\int_{\Omega} Y_{lm}(\theta,\phi)^{2} \, d\omega = 1$$
**代码对应：**
```c
float K(int l; int m) {
    float temp = ((2.0 * l + 1.0) * factorial(l - m)) / (4.0 * PI * factorial(l + m));
    return sqrt(temp);
}
```

##### 2.2.3.3 P() 函数 - 伴随勒让德多项式（上述实数形式中$P_{l}^{m}(cos \theta)$项）
计算$P_{l}^{m}(x)$，其中$x = cos \theta$

使用**伴随勒让德多项式（Associated Legendre Polynomials）**的**递推公式（Recurrence Relations）**。这是一种标准的数值计算方法，因为它比直接套用通项公式更稳定，计算量也更小。这种算法通常被称为“**Robin Green 递归方案**”或源自《Numerical Recipes in C》，具体分为三个步骤进行计算。

第一步：计算对角线项 $P_m^m(x)$
代码首先计算 $l=m$ 时的值。这对应矩阵的对角线部分。

**数学公式：**
$$P_m^m(x) = (-1)^m (2m-1)!! (1-x^2)^{m/2}$$
其中 $(2m-1)!!$ 是双阶乘（即 $1 \times 3 \times 5 \times ...$）。

**代码对应：**
```c
float pmm = 1.0;
if(m > 0) {
    // 1. somx2 即 sqrt(1-x^2)，也就是 sin(theta)
    float somx2 = sqrt((1.0 - x) * (1.0 + x)); 
    float fact = 1.0;
    
    // 2. 循环实现双阶乘 (1 * 3 * 5...) 和 (-1)^m
    for(int i = 1; i <= m; i++) {
        pmm *= (-fact) * somx2; // 乘上负的双阶乘项和 sin(theta)
        fact += 2.0;            // fact 每次加2 (1, 3, 5...)
    }
}
if(l == m) return pmm;
```
*   如果 $l=m$，计算到这就结束了，直接返回 `pmm`。

---

第二步：计算上一层 $P_{m+1}^m(x)$
如果有必要（即 $l > m$），代码会利用 $P_m^m$ 算出 $P_{m+1}^m$。这是一个特殊的垂直递推关系。

**数学公式：**
$$P_{m+1}^m(x) = x(2m+1)P_m^m(x)$$

**代码对应：**
```c
// pmmp1 代表 P(m+1, m)
float pmmp1 = x * (2.0 * m + 1.0) * pmm;
if(l == m + 1) return pmmp1;
```
*   这里直接用上一步算出的 `pmm` 乘以 $x(2m+1)$。
*   如果 $l = m+1$，计算结束，返回 `pmmp1`。

---

第三步：一般递推 $P_l^m(x)$
如果 $l$ 比 $m+1$ 还要大，代码会进入一个循环，利用前两项算出当前项。这是标准的**三项递推公式**。

**数学公式：**
$$(l-m)P_l^m(x) = (2l-1)x P_{l-1}^m(x) - (l+m-1)P_{l-2}^m(x)$$

为了求 $P_l^m$，将公式变形为代码中的形式：
$$P_l^m(x) = \frac{(2l-1)x P_{l-1}^m - (l+m-1)P_{l-2}^m}{l-m}$$

**代码对应：**
```c
float pll = 0.0;
// 从 m+2 开始循环直到目标 l
for(int ll = m + 2; ll <= l; ++ll) {
    // 套用上面的公式：
    // pmmp1 是上一项 (l-1)
    // pmm   是上上一项 (l-2)
    pll = (((float)(2.0 * ll) - 1.0) * x * pmmp1 - ((float)(ll + m) - 1.0) * pmm) / (ll - m);
    
    // 更新变量，为下一次循环做准备
    pmm = pmmp1;
    pmmp1 = pll;
}
return pll;
```

---
总结
1.  先算**基底**：$P_m^m$（利用双阶乘）。
2.  再算**一步**：$P_{m+1}^m$。
3.  最后**爬升**：通过循环不断推导更高阶的 $l$，直到达到目标 $l$。

这种方法避免了直接计算阶乘带来的浮点溢出问题，是计算机图形学中计算球谐函数的标准做法。

#### 2.2.4 加权累加到系数矩阵

```c
float contribution = val * sh_basis * solid_angle; 
float current_val = getcomp(sh_coeffs, r, c); 
setcomp(sh_coeffs, current_val + contribution, r, c);
```

这是**累加过程**，每个样本都对所有球谐系数有贡献，贡献值 = 距离值 × 基函数值 × 立体角权重。

## 3. 存储结构

### 3.1 系数矩阵布局

```c
// 球谐系数的索引方式 
int idx = l * (l + 1) + m;  // 线性索引 
int r = idx / 4;           // 矩阵行 
int c = idx % 4;           // 矩阵列
```

对于16个系数（l=0..3）：

```c
索引映射： 
l=0, m=0 -> idx=0 
l=1, m=-1 -> idx=1 
l=1, m=0 -> idx=2 
l=1, m=1 -> idx=3 
... 
l=3, m=3 -> idx=15
```

存储在4×4矩阵中，可以理解为：
- 前4个系数在矩阵第0行
- 接下来4个在第1行
- 以此类推

## 4. 重建过程（反向使用）

投影完成后，可以通过这些系数**重建**任意方向的距离近似值：

```c
float approximate_distance(float theta, float phi) {
     float sum = 0.0;     
     for (int l = 0; l < bands; l++) {
        for (int m = -l; m <= l; m++) {
            int idx = l * (l + 1) + m;
            float coefficient = get_coefficient(idx);  // 从矩阵读取
            float basis = SH(l, m, theta, phi);
            sum += coefficient * basis;
        }
    }     
    return sum; 
} 
```

## 5. 技术细节

1. **采样数影响精度**：
    - 样本越多，蒙特卡洛积分越精确
    - 但计算成本线性增加
2. **带数限制**：
    - 代码限制为4阶（bands=4），16个系数
    - 更高阶可捕获更多细节，但需要更多样本避免走样
3. **半球 vs 全球**：
    - 代码只在半球采样（因为法线方向）
    - 但基函数是全球定义的，投影结果隐含了半球外函数值为0的假设
这种投影方法广泛用于**预计算辐射度传输**、**环境遮挡**、**次表面散射**等高级渲染技术中。

## 6. 完整VEX代码
```c
// ---------------------------------------------------------
// SH Helper Functions
// ---------------------------------------------------------

float factorial(int i) {
    float f[] = {1, 1, 2, 6, 24, 120, 720, 5040, 40320, 362880, 3628800, 39916800, 479001600};
    if(i < len(f)) return f[i];
    return 1.0; 
}

float P(int l; int m; float x) {
    float pmm = 1.0;
    if(m > 0) {
        float somx2 = sqrt((1.0 - x) * (1.0 + x));
        float fact = 1.0;
        for(int i = 1; i <= m; i++) {
            pmm *= (-fact) * somx2;
            fact += 2.0;
        }
    }
    if(l == m) return pmm;
    float pmmp1 = x * (2.0 * m + 1.0) * pmm;
    if(l == m + 1) return pmmp1;
    float pll = 0.0;
    for(int ll = m + 2; ll <= l; ++ll) {
        pll = (((float)(2.0 * ll) - 1.0) * x * pmmp1 - ((float)(ll + m) - 1.0) * pmm) / (ll - m);
        pmm = pmmp1;
        pmmp1 = pll;
    }
    return pll;
}

float K(int l; int m) {
    float temp = ((2.0 * l + 1.0) * factorial(l - m)) / (4.0 * PI * factorial(l + m));
    return sqrt(temp);
}

float SH(int l; int m; float theta; float phi) {
    float sqrt2 = 1.41421356;
    if(m == 0) return K(l, 0) * P(l, m, cos(theta));
    else if(m > 0) return sqrt2 * K(l, m) * cos(m * phi) * P(l, m, cos(theta));
    else return sqrt2 * K(l, -m) * sin(-m * phi) * P(l, -m, cos(theta));
}

// --- 新增：手动实现均匀半球采样 ---
// 输入: 两个0-1的随机数
// 输出: 局部空间下的单位向量 (Z轴朝上)
vector sample_hemisphere_uniform(vector2 u) {                                 
    float phi = u.x * 2.0 * PI;
    float z = u.y; // 在高度上均匀分布
    float r = sqrt(1.0 - z * z);
    return set(r * cos(phi), r * sin(phi), z);
}

// ---------------------------------------------------------
// Main Code
// ---------------------------------------------------------

int samples = chi("samples");       
int bands = chi("bands");           
float max_dist = chf("max_dist");
float ray_bias = chf("ray_bias"); 
int input_geo = 1;                  

matrix sh_coeffs = 0;
float solid_angle = 2.0 * PI / (float)samples; 

vector2 seed = set(@Time, @ptnum * 0.123);

// --- 构建切线空间 ---
// 目标方向：法线的反方向 (-N)
vector n_inv = -normalize(@N); 

// 构建坐标系
vector up = set(0,1,0);
if (abs(n_inv.y) > 0.99) up = set(1,0,0);
vector x_axis = normalize(cross(up, n_inv));
vector y_axis = normalize(cross(n_inv, x_axis));

// 变换矩阵：将局部Z轴映射到 n_inv
matrix3 basis_mat = set(x_axis, y_axis, n_inv);

// --- 计算起点 ---
vector origin = @P + (n_inv * ray_bias);

for(int i = 0; i < samples; i++) {
    
    vector2 u = rand(seed + set(i * 0.34, i * 0.78));
    
    // 1. 调用手动实现的半球采样函数
    vector local_dir = sample_hemisphere_uniform(u); 
    
    // 2. 旋转到世界空间
    vector dir = local_dir * basis_mat;
    
    // 3. 射线检测
    vector hit_pos;
    float u_uv, v_uv;
    
    int prim = intersect(input_geo, origin, dir * max_dist, hit_pos, u_uv, v_uv);
    
    float val = 0.0;
    
    if (prim != -1) {
        val = distance(@P, hit_pos);
    } else {
        val = max_dist; 
    }
    
    // 4. SH 投影
    float theta = acos(dir.z); 
    float phi = atan2(dir.y, dir.x);
    if(phi < 0) phi += 2 * PI;
    
    for (int l = 0; l < bands; l++) {
        for (int m = -l; m <= l; m++) {
            int idx = l * (l + 1) + m;
            
            if (idx < 16) {
                float sh_basis = SH(l, m, theta, phi);
                float contribution = val * sh_basis * solid_angle;
                
                int r = idx / 4;
                int c = idx % 4;
                
                float current_val = getcomp(sh_coeffs, r, c);
                setcomp(sh_coeffs, current_val + contribution, r, c);
            }
        }
    }
}

// ---------------------------------------------------------
// Output
// ---------------------------------------------------------
4@thickness_sh = sh_coeffs;

```
